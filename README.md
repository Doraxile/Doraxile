## Featured Projects

### 🌫️ [Air Quality Classification — Jakarta](https://github.com/Doraxile/air-quality-classification) *(Thesis)*
> Binary classification model predicting DKI Jakarta air quality using Random Forest. Achieved **98.05% accuracy** and **0.97 macro F1-score** on 2,570 records. Validated with 5-fold Stratified K-Fold CV, Permutation Feature Importance, and Partial Dependence Plots for interpretable environmental insights.

`Python` `scikit-learn` `pandas` `Random Forest` `Matplotlib` `Seaborn`

---

### ✋ [Real-Time Hand Gesture Volume Controller](https://github.com/Doraxile/hand-gesture-audio-control)
> Computer vision app that maps hand pinch gestures to Windows audio in real time — depth-compensated volume control, adaptive EMA smoothing, gesture mute/unmute, and media playback control. Built with modular OOP architecture and a custom transparent HUD overlay.

`Python` `OpenCV` `MediaPipe` `NumPy` `Pycaw`

🌐 **[Try the live web demo](https://Doraxile.github.io/hand-gesture-audio-control/)** — no installation required

---

### 📉 [Customer Churn Classification](https://github.com/Doraxile/customer-churn-classification)
> End-to-end churn prediction pipeline on the IBM Telco dataset. Includes 9 engineered features, scikit-learn Pipeline with OneHotEncoding, and hyperparameter tuning via RandomizedSearchCV. Evaluated with F1-Score, Precision, Recall, and Confusion Matrix.

`Python` `scikit-learn` `pandas` `Pipeline` `RandomizedSearchCV`

---

### 🧑‍💼 Face Recognition Attendance System *(in progress)*

`Python` `InsightFace` `ArcFace` `FAISS` `SQLAlchemy`
